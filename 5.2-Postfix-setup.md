# Setting Mail server in Ubuntu 22

## Initial server setup

### Set server domain name

```bash
sudo apt -y update; sudo apt -y upgrade
sudo echo 'dev.dsinnovators.com' > /etc/hostname
sudo sed -i 's/\(127.0.0.1\).*/\1 dev.dsinnovators.com/' /etc/hosts
sudo reboot now
```

## Setup Mail Transfer Agent

### Install required packages

```bash
sudo apt install -y mailutils
sudo apt install -y postfix
```

### Update Postfix configuration

```bash
sudo dpkg-reconfigure postfix
> Internet Site
> System mail name: dev.dsinnovators.com
> Recipient for root: <enter>
> Other destinations to accept mail: dev.dsinnovators.com, localhost.dsinnovators.com, dsinnovators.com
> Force synchronous updates: <No>
> Local networks: 127.0.0.0/8 [::ffff:127.0.0.0]/104 [::1]/128
> Mailbox size limit: 0
> Local address extension character: +
> Internet protocols to use: all
```

Custom configuration

```bash
sudo vi /etc/postfix/main.cf

# Update
home_mailbox = Maildir/
inet_interfaces = loopback-only
masquerade_domains = dev.dsinnovators.com
```

### Reload Postfix

```bash
sudo systemctl reload postfix
postconf -n
```

### Verify server connection

```bash
telnet smtp.google.com 25
> ehlo smtp.google.com
```
