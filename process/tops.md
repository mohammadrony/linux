## Htop

## Btop

Installation

```bash
sudo apt install -y btop
# or
sudo snap install btop
```

Usage

```bash
btop
```

### sysinfo cli

```bash
curl https://raw.githubusercontent.com/jedrecord/sysinfo/master/sysinfo -o sysinfo
chmod +x sysinfo
sudo mv sysinfo /usr/local/bin/sysinfo
```
