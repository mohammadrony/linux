# pidstat

```bash
pidstat
```

```bash
pidstat -p ALL
```

Start program and monitor

```bash
pidstat -e <program> <args>
```

Task threads status

```bash
pidstat -t
```

Process status

```bash
pidstat -p <pid>
```

```bash
pidstat -C <command>
```

Display multiple report

```bash
pidstat -p <pid> <interval> <count>
```
