# Change Modification

## Restore

Restore file in current branch

```bash
git restore *.file
```

```bash
git restore ./path/to/file
```

## Stash

Save changes

```bash
git stash
```

Apply latest stash

```bash
git stash apply
git stash drop
```

```bash
git stash pop
```

Clear all saved copy

```bash
git stash list
git stash clear
```
