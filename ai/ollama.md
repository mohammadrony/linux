# Ollama

Installation

```bash
curl -LO https://ollama.com/install.sh

sh install.sh
rm -f install.sh
```

## Commands

Start server

```bash
ollama serve
```

List models

```bahs
ollama list
```

Run model

```bash
ollama run MODEL
```

Stop model

```bash
ollama stop MODEL
```

Remove model

```bash
ollama rm MODEL
```
