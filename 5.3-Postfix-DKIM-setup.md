## Initial server setup

### Configure server domain name

```bash
sudo apt -y update; sudo apt -y upgrade
sudo echo 'dev.dsinnovators.com' > /etc/hostname
sudo sed -i 's/\(127.0.0.1\).*/\1 dev.dsinnovators.com/' /etc/hosts
sudo timedatectl set-timezone Asia/Dhaka
sudo reboot now
```

## Setup Mail Transfer Agent

### Install required packages

```bash
sudo apt install -y postfix
sudo apt install -y mailutils
```

### Update Postfix configuration

```bash
sudo dpkg-reconfigure postfix
> Internet Site
> System mail name: dev.dsinnovators.com
> Recipient for root: <enter>
> Other destinations to accept mail: dev.dsinnovators.com, localhost.dsinnovators.com, localhost
> Force synchronous updates: <No>
> Local networks: 127.0.0.0/8 [::ffff:127.0.0.0]/104 [::1]/128
> Mailbox size limit: 0
> Local address extension character: +
> Internet protocols to use: all
```

Custom configuration

```bash
sudo vi /etc/postfix/main.cf

# Update
home_mailbox = Maildir/
inet_interfaces = loopback-only
masquerade_domains = dev.dsinnovators.com
```

### Reload Postfix

```bash
sudo systemctl restart postfix
postconf -n
```

### Verify server connection


## DKIM key setup

### Install DKIM packages

```bash
sudo apt install -y opendkim opendkim-tools
```

### Add Postfix user to OpenDKIM group

```bash
sudo usermod -aG opendkim postfix
```

### Setup OpenDKIM key directory

```bash
sudo mkdir -p /etc/opendkim/keys
sudo chown -R opendkim:opendkim /etc/opendkim
sudo chmod  744 /etc/opendkim/keys
```

### Generate DKIM key for website

```bash
sudo mkdir /etc/opendkim/keys/dev.dsinnovators.com
sudo opendkim-genkey -b 2048 -d dev.dsinnovators.com -D /etc/opendkim/keys/dev.dsinnovators.com -s default -v
sudo chown opendkim:opendkim /etc/opendkim/keys/dev.dsinnovators.com/default.private
```

### Update DKIM key in DNS record

```bash
sudo cat /etc/opendkim/keys/dev.dsinnovators.com/default.txt

# Output
default._domainkey IN TXT ("v=DKIM1; h=sha256; k=rsa; p=Encrypted_key");
```

### Verify the DNS record

```bash
sudo opendkim-testkey -d dev.dsinnovators.com -s default -vvv
```

### Update DKIM configuration

```bash
sudo vi /etc/opendkim.conf

# Update
LogWhy                  yes
Mode                    sv
# SubDomains              no

# Add
AutoRestart             yes
AutoRestartRate   	    10/1M
Background              yes
DNSTimeout              5
SignatureAlgorithm      rsa-sha256

# End of the file
KeyTable                refile:/etc/opendkim/key.table
SigningTable            refile:/etc/opendkim/signing.table
ExternalIgnoreList      /etc/opendkim/trusted.hosts
InternalHosts           /etc/opendkim/trusted.hosts
```

## Additional DKIM Files

### Update Signing table

```bash
sudo vi /etc/opendkim/signing.table

# Add
```

```bash
# Add
```


## Configuring Postfix With OpenDKIM


### Update OpenDKIM socket file

```bash
sudo mkdir /var/spool/postfix/opendkim
sudo chown opendkim:postfix /var/spool/postfix/opendkim
```

### Update configuration file

```bash
sudo vi /etc/opendkim.conf

# Update
Socket    local:/var/spool/postfix/opendkim/opendkim.sock
```

### Update OpenDKIM configuration

```bash
sudo vi /etc/default/opendkim

# Update
SOCKET="local:/var/spool/postfix/opendkim/opendkim.sock"
```

### Update Postfix configuration

```bash
sudo vi /etc/postfix/main.cf

# Add
# Milter configuration
milter_default_action = accept
milter_protocol = 6
smtpd_milters = local:opendkim/opendkim.sock
# smtpd_milters = local:/var/spool/postfix/opendkim/opendkim.sock
non_smtpd_milters = $smtpd_milters
```

### Restart services

```bash
sudo systemctl restart opendkim
sudo systemctl restart postfix
```
