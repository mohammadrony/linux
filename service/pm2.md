# PM2

## Prerequisites

[Install Nodejs and NPM](../packages/node-npm.md)

## Installation

```bash
npm install -g pm2
```

## Commands

Application list

```bash
pm2 list
```

Start application

```bash
pm2 start app.js
```

Auto restart service

```bash
pm2 startup
```

```bash
sudo env PATH=$PATH:...
```

```bash
pm2 save
```
