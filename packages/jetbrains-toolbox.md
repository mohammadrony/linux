# Jetbrains Toolbox

- Download Toolbox from [JetBrains](https://www.jetbrains.com/toolbox-app/).

Install prerequisites

```bash
sudo apt install -y libfuse2
```

Extract package

```bash
tar -xvzf jetbrains-toolbox-xxx.tar.gz
```

Install toolbox

```bash
jetbrains-toolbox-*/jetbrains-toolbox
```
